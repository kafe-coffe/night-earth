# Ночная Земля

Одностраничный сайт: ночная Земля на фоне вращается при прокрутке страницы.

- Один файл `index.html`, без сборки и внешних скриптов (шрифты подгружаются с Google Fonts).
- Планета рисуется на WebGL: контуры материков, огни городов, облака и свечение атмосферы генерируются в браузере.
- Контуры материков схематичны. Чтобы повысить качество, замените генерацию текстуры в `buildTexture()` на готовые карты Земли и ночных огней.

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.
